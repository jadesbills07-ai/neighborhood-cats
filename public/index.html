Join your town

Enter a display name and your 5-digit Maine ZIP code, then pick your county and town. There is no neighborhood code any more — the old lisbon-cats code is no longer used. You are locked to your own town only: there is no View All Maine and no browsing other towns. No phone number or email is shown to anyone.

Not confirmed yet. Tap “Confirm my location” to GPS-confirm, or join with your ZIP only (marked unverified). GPS confirmation improves accuracy, but it is not required — and GPS never blocks you: there is no ZIP-boundary check, so a neighbor at a town edge is not rejected for a GPS mismatch. Your GPS coordinates are never stored as your home location.

Town suggestions come from towns already added in that county. If your town is not listed yet, just type it in — it will be added when the first cat from that town is added.

When an Indoor Only cat is spotted in your town, you get a flashing banner that stays until dismissed, plus (if loud alerts are on) an alert sound, phone vibration on Android, and a browser notification if you allowed notifications. Honest limit: a web app cannot override silent / Do Not Disturb, and cannot reliably wake a fully closed browser without a native app and push service.

If the map does not load, the cat list below still works.

Tap the map to place your cat's approximate pin when adding a cat. Pins are approximate by design.

Emergency Details (optional — all fields optional)

These details are hidden in normal mode. They only become visible to everyone in your town if this cat is marked Lost / Emergency — or, for the exact address only, if you tick “Always show my exact address” below. Fill in only what you are comfortable sharing in an emergency.

If you set a PIN, it is required to turn Emergency Mode on and off. If you do not set one, anyone in town could toggle it — set a PIN first if you can.
